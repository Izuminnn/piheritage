Thêm, sửa, xoá địa điểm trong thư viện di sản và dự án riêng của khách hàng. Mỗi lần bấm LƯU LÊN WEB, trang ghi thẳng vào kho GitHub của website — web tự cập nhật sau khoảng 1–2 phút.

Cách lấy token GitHub — người quản lý kho làm một lần
  1. Đăng nhập GitHub bằng tài khoản sở hữu kho website, vào Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Token name: đặt tên dễ nhớ, ví dụ PiHeritage quản trị. Expiration: chọn 1 năm.
  3. Repository access: chọn Only select repositories → chọn đúng kho website.
  4. Permissions → Repository permissions → Contents: chọn Read and write. Các quyền khác để nguyên.
  5. Bấm Generate token, chép chuỗi bắt đầu bằng github_pat_… rồi gửi riêng cho anh em cần dùng.
  6. Ai nghỉ việc hoặc lỡ để lộ token: vào lại trang đó, xoá token cũ, tạo token mới.

Kết nối với GitHub

Phần sau github.com/ trong địa chỉ của kho.

Token chỉ lưu trong trình duyệt của máy này, không gửi đi đâu ngoài GitHub.
